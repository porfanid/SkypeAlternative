## 🚀 Future: Call Credits System

**Coming in Version 2.0!**

We're planning to introduce an optional credit system for video/audio calls:

### How It Will Work

1. **Free Tier** (Always Available)
   - Unlimited text messaging
   - Basic voice calls (limited duration)
   - All core features

2. **Credits System** (Optional)
   - Purchase credits for extended call time
   - $10 = 1000 minutes (~16.5 hours)
   - No subscription required
   - Credits never expire
   - Support the project while you use it

3. **Supporter Benefits**
   - Monthly sponsors get bonus credits
   - Enterprise sponsors get unlimited calls

**Why Credits?**
- Video calls are expensive (bandwidth, infrastructure)
- Sustainable model for long-term operation
- Fair pay-for-what-you-use system
- Keeps text chat always free
- Supports development and infrastructure

### Transparency Pledge

When credits launch:
- Detailed breakdown of infrastructure costs
- Open financials (revenue vs. expenses)
- Community input on pricing
- Always keep core messaging free

## ❓ FAQ

**Q: Is SkypeAlternative really free?**
A: Yes! Core messaging features are and will always be free and open source. Call credits (coming soon) are optional for extended video call time.

**Q: Why not use ads instead?**
A: Ads compromise privacy. We'll never track users or sell data. We're committed to privacy-first funding models.

**Q: Can I use this for my business?**
A: Yes! The code is MIT licensed. For enterprise support, contact us about sponsorship or enterprise plans.

**Q: What happens to my donation?**
A: All donations go directly to project costs (infrastructure, security audits, development). We publish financial reports for transparency.

**Q: Can I donate anonymously?**
A: Yes! You can donate without being publicly listed if you prefer.

**Q: How do I cancel my sponsorship?**
A: You can cancel anytime through GitHub Sponsors. No questions asked, no hard feelings.

**Q: Do you offer refunds?**
A: Sponsorships are non-refundable, but you can cancel anytime. One-time donations are final.

**Q: Is my donation tax-deductible?**
A: Currently no. If the project moves to a 501(c)(3) non-profit in the future, we'll update this.
