The Copilot Instructions document contains:

- **Security First Principles** - Guidelines for secure coding practices
- **Code Quality Standards** - TypeScript, React, and testing standards
- **Architecture Patterns** - Service layer, state management, and Firebase integration
- **Naming Conventions** - Files, directories, and code naming standards
- **Comments and Documentation** - JSDoc format and when to comment
- **Error Handling** - Best practices for error handling
- **Performance Considerations** - Optimization strategies
- **Accessibility Requirements** - WCAG compliance guidelines
- **Electron-Specific Guidelines** - Security and IPC best practices
- **Git Commit Message Format** - Conventional commits format
- **Security Checklist** - Pre-commit security validation
- **Code Review Focus Areas** - What to look for in PRs
- **Resources** - Links to relevant documentation

## Why in .github?

The Copilot instructions are kept in the `.github` directory because:
1. GitHub Copilot automatically reads instructions from `.github/copilot-instructions.md`
2. This is the standard location for GitHub-specific configuration
3. It keeps the instructions close to other GitHub configurations (workflows, templates)
